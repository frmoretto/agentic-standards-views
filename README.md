# Agentic Standards Map views

Thematic views built on the data of the [Agentic Standards Map](https://frmoretto.github.io/agentic-standards-map/) (concept DOI [10.5281/zenodo.23357361](https://doi.org/10.5281/zenodo.23357361)).

Site: https://frmoretto.github.io/agentic-standards-views/

## Views

- [What agentic commerce needs from each AAIF group](https://frmoretto.github.io/agentic-standards-views/commerce-needs-aaif.html): the steps of a purchase made by an agent, the AAIF working group that should own each question, and the public work that addresses it; plus every source of the map sorted by the AAIF group that should follow it. Data: map version 1.5 and the corrections published on 2026-11-16.

## How a view relates to the map

- The map records public standardisation activity, dated and sourced, and ranks nothing. A view adds a reading from one angle (for example, which group should own which question). That reading is the author's, offered for correction; it is not a position of AAIF or of any body described.
- Each view states the map version its data comes from. Entries are written and corrected only in the map.
- Only public sources are used.

## Contributing

Open an issue or a pull request on this repository for the views. Corrections to an entry (status, dates, sources) go to [the map's repository](https://github.com/frmoretto/agentic-standards-map/issues).
